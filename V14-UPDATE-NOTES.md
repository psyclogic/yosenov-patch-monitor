# V14

Tambahan opsi sort **Game terbaru ditambahkan** pada:

- Admin → Kelola status terjemahan
- Dashboard utama
- View Mode

Urutan menggunakan field `createdAt` secara descending. Game yang paling baru masuk ke library YOSENOV akan berada paling atas. Data lama yang tidak memiliki `createdAt` ditempatkan setelah game yang memiliki tanggal penambahan, lalu diurutkan berdasarkan nama.
