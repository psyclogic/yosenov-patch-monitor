# YOSENOV V7

- Single-game Blogspot embed dipadatkan untuk smartphone, tablet, dan desktop tanpa scrollbar internal.
- Build lokal/publik/terjemahan tetap tiga kolom pada layar kecil.
- Status tetap dua kolom pada layar kecil.
- Iframe menggunakan `scrolling="no"` dan tinggi responsif sebagai fallback lintas perangkat.
- Admin menyediakan dua kode embed: Dengan border dan Tanpa border.
- Mode `border=0` menghilangkan border kartu internal agar menyatu dengan artikel Blogspot.
